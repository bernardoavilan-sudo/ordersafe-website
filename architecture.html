System Architecture

OrderSafe is built for high availability, low latency, and deep offensive intelligence. The system is deployed as a microservice API ready to be integrated into any payment gateway.

Tech Stack

  • Backend Engine: Python (Flask)
  • AI Inference: Groq Cloud (LLaMA 3 70B/8B - High-speed latency)
  • Database: PostgreSQL (Neon.tech) for persistent event logging
  • Hosting: Render (Backend) / Vercel (Frontend)

API Payload Example

POST /test/analyze
{
  "email": "test@mailinator.com",
  "ip": "104.28.212.10",
  "amount": 1200,
  "shipping_country": "US",
  "billing_country": "RU",
  "threeds_verified": false
}

The engine returns a JSON response with the score, level, action, and an explainable AI (XAI) reasoning field.
